
# Hospital Module

Модуль **Hospital** створено для управління медичними процесами, такими як облік пацієнтів, лікарів, відвідувань, діагнозів тощо. Він належить до категорії **Human Resources** в системі **Odoo**. Основна мета цього модуля — покращити та автоматизувати процеси в медичних установах. Нижче подано опис його структури та функціональних можливостей.

## Включені компоненти

### SECURITY
- Модуль містить файл **`ir.model.access.csv`**, який відповідає за налаштування доступів до моделей та їх об'єктів.

### WIZARD
1. **`hr_hospital_personal_doctor_wizard_views.xml`**: Майстер, за допомогою якого можна призначати чи змінювати особистого лікаря пацієнта.
2. **`hr_hospital_report_diseases_wizard_views.xml`**: Майстер для формування звітів за захворюваннями.

### VIEWS
- **`hr_hospital_visit_views.xml`**: Облік візитів пацієнтів до лікарів.  
- **`hr_hospital_doctor_views.xml`**: Управління даними про лікарів.  
- **`hr_hospital_patient_views.xml`**: Перегляд інформації про пацієнтів.  
- **`hr_hospital_disease_views.xml`**: Перелік доступних захворювань.  
- **`hr_hospital_diagnosis_views.xml`**: Діагностичні записи та висновки.  
- **`hr_hospital_disease_type_views.xml`**: Типологія захворювань.  
- **`hr_hospital_menu.xml`**: Головне меню для доступу до функціоналу модуля.

### DATA
- **`hr_hospital_disease_data.xml`**: Попередньо завантажені дані щодо захворювань (наприклад, список поширених хвороб).

### DEMO ДАНІ
Модуль містить демонстраційні дані для полегшення тестування:
- **`hr_hospital_doctor_demo.xml`**: Демонстраційні записи про лікарів.  
- **`hr.hospital.patient.csv`**: Дані щодо зразкових пацієнтів.

## Функціонал модуля
1. **Облік лікарів:**  
   Інформація про лікарів, їх спеціалізації, графік прийому та доступність.

2. **Реєстрація пацієнтів:**  
   Дані про пацієнтів, включаючи їх загальну інформацію, медичні показники, історію хвороб.

3. **Управління захворюваннями та діагнозами:**  
   - Список хвороб із категоризацією за типами.  
   - Призначення діагнозів пацієнтам.

4. **Облік прийомів:**  
   Запис пацієнтів на прийоми та ведення журнала візитів.

5. **Звіти:**  
   Майстри для генерування звітів, наприклад, за поширеністю захворювань.
